# 存念（apo-cunnian）

遵循《打造第二大脑》信管法则（CODE）全流程的个人第二大脑，以 DeepSeek Harness 插件形态运行：

**抓取 → 组织 → 提炼 → 表达**

- 抓取：手动录入 + 飞书群机器人 webhook，共鸣轻判断 + 十二个兴趣问题对照
- 组织：PARA 四桶（项目/领域/资源/存档）+ 归档 AI 建议
- 提炼：渐进式归纳工作台（触碰时 AI 建议加层，人工确认）
- 表达：半熟素材 + 群岛式起草 + 海明威之桥 + 导出 Markdown

> 本仓库同时是一篇 mattpocock/skills 工作流教程的开发实录：`.agents/skills/` 中的技能与 `docs/agents/` 中的配置即为真实工程配置。
