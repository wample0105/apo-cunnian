# 存念（cunnian）

遵循 PARA 的个人本地知识库（第二大脑），以 DeepSeek Harness 插件形态运行：

**灵感收集 → 整理归桶 → 管理检索 → 辅助创作**

- 收集：插件内手动录入 + 飞书群机器人 webhook 接收
- 整理：AI 辅助打标、按 PARA 归桶建议
- 管理：Project / Area / Resource / Archive 四桶浏览与全文检索
- 创作：从知识库选题 → 引用素材 → AI 辅助成文 → 导出 Markdown

> 本仓库同时是一篇 mattpocock/skills 工作流教程的开发实录：`.agents/skills/` 中的技能与 `docs/agents/` 中的配置即为真实工程配置。
