# 条目以纯 Markdown+frontmatter 存储，不引入数据库

知识库的真相源是「一个条目一个 md 文件」，元数据（共鸣命中、触碰计数、层级信息、半熟素材类型）全部存 YAML frontmatter，不引入 SQLite 等数据库。理由：旧存念 255 文件直接兼容、桌面版成果预览原生可读、AI 与人可直改、损坏可肉眼修复；查询性能问题留给将来按需增加的索引层（只读缓存，可随时重建）。

## Considered Options

- SQLite 为真相源：查询强但文件不可直读，旧数据要迁移，与成果预览形态割裂。
- md+SQLite 混合：两套数据同步是长期维护负担，v1 复杂度不值。

## Consequences

- 全文检索与统计依赖遍历或外部工具（个人量级可接受）。
- frontmatter 字段是事实上的公共契约，改动需考虑既有条目迁移。
